Talaria design variants

Requirements are frozen (see Navigation). Four visual directions for the frozen screens: inbox, text chat, voice chat, a recording expanded in place, the recorder, and the Lock Screen. Same content everywhere, only the styling changes.

Glass · chosen

iOS 26 layers over a soft tint, tight corners, no shadows. The reference for everything below.

Paper

Warm off-white with flat cards and hairlines, green accent, coral for recording. Same rules as Glass, warmer mood.

Slate

Dark graphite with an indigo accent. Calm dark mode rather than a terminal: no mono, no glow, the same layout as Glass. Light version →

Tide

Cool light gray, one teal accent, flat and crisp with slightly smaller radii. The least decorated of the four.

Chosen: Glass. Navigation study → three ways to get around, sessions and recordings included. Tasks study → the hermes kanban as one list with a triage deck.

Run: cd docs/design && npx http-server -o (or open index.html directly; no build step, no dependencies).

What to react to: the overall feel first, then the composer and model pill, the approval card, the recorder buttons, and the recordings rows. Mixing is fine: "Glass, but Console's approval card" is a valid answer.
