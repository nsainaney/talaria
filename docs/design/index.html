Talaria design variants

Four directions for the same four screens: chat, recording mode, recordings, and the Lock Screen widget with the Live Activity. Same content everywhere, only the styling changes.

1 · Ink

Quiet and typographic. Near-monochrome, hairline dividers, one red accent reserved for recording. The chat reads like a document rather than a messenger.

2 · Glass

Follows iOS 26: translucent layers over a soft tinted background, big radii, floating composer and controls. Familiar system feel with a warmer palette.

3 · Console

Dark, dense, made for an agent. Amber accent, mono details for tools and commands, approval cards that look like a terminal prompt. The recorder glows.

4 · Paper

Warm off-white, rounded cards with soft shadows, a green accent for "done" and a coral one for recording. Friendlier and less technical.

Run: cd docs/design && npx http-server -o (or open index.html directly; no build step, no dependencies).

What to react to: the overall feel first, then the composer and model pill, the approval card, the recorder buttons, and the recordings rows. Mixing is fine: "Glass, but Console's approval card" is a valid answer.
